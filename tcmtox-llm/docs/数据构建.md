# 数据构建：SFT 指令数据集设计与产出

> 从 TCMToxDB 4 张表 +《中国药典》2020 参考表构建 6,234 条多任务指令数据。
> 构造器 `scripts/build_sft_data.py`（SEED=42，确定性再生）。

## 设计原则

1. **可溯源**：每条答案完全来自表字段，`meta.src` 记录来源表与主键
2. **拒答优先**：医疗幻觉致命，专门构造"数据里没有"的样本（T6），教模型承认不知道
3. **模板多样化**：每任务 3~5 个问法变体（正式/口语/英文），防学模板不学知识
4. **难度分层**：单跳问答 → 多跳检索 → 分析推理
5. **口径统一**：分级冲突按药典 2020 校正，答案注明依据

## 数据源

| 来源 | 可用字段 | 备注 |
|---|---|---|
| `TCMTox_herb_clean.csv`（229 味） | 名称、性味归经、功效、主治、**分级（72 味）**、临床毒性表现 | 清洗产物，含 grade/source/conflict/original 四列 |
| `yd2020_toxic83.csv`（83 种） | 分级、**用法用量**、**注意事项** | 安全用药问答的核心弹药 |
| `TCMTox_formula.csv`（1555 方） | 方名、处方、剂型、疾病、证候、功效 | 处方为**拼音+炮制前缀+投料量** |
| `TCMTox_ingredient.csv`（9377） | 成分名、SMILES、CAS、PubChem/DrugBank ID | 无草药关联（HBIN join 问题），仅单表问答 |
| `TCMTox_target.csv`（7885） | 靶点名、UniProt、**毒性类型标注**（16 类） | 全英文，双语模板 |

两个影响任务设计的关键事实：

- **处方文本是拼音**（`Chao Qian Niu Zi 200g`），需词典匹配 + 炮制前缀剥离；
  剂量是**投料量 ≠ 日服量**——剂量对比类样本绝不输出"超量/安全"结论
- **成分表与草药表 ID 体系不通**（HBIN vs HERB00xxx），成分→草药关联任务暂缓

## 任务定义（T1~T7）

| 任务 | 覆盖内容 | 子类 |
|---|---|---|
| T1 单药毒性问答 | 分级（中/英）、性味归经、临床毒性表现、药用部位/拉丁名 | T1a~f |
| T2 药典安全用药 | 用法用量、注意事项、孕妇禁忌、配伍禁忌（十八反十九畏） | T2a~e |
| T3 方剂毒性分析 | 处方解析 → 毒性药材 + 分级 + 投料量（多跳） | T3a~d |
| T4 靶点与成分事实 | 靶点毒性类型（16 类，双语）、UniProt、SMILES/CAS/PubChem | T4a~f |
| T5 剂量对比 | 投料量 vs 药典用量；答案结构：药典用量 → 投料量≠日服量 → **不下断言结论** | T5 |
| T6 拒答与边界 | T6a 库外药 / T6b 不存在药 / T6c 缺失关联 / T6d 医疗建议 / T6e 口径冲突纠错 | T6a~e |
| T7 反向检索 | 分级列表、孕妇禁用清单、配伍反查、方剂反查、数据库概况 | T7a~f |

样本格式（alpaca，`meta` 不参与训练仅溯源）：

```json
{"instruction": "...", "input": "", "output": "...",
 "meta": {"task": "T1a", "key": "HERB000123", "lang": "zh", "src": ["..."]}}
```

验证通过（川乌=大毒、半夏=有毒、天仙子=大毒）；语言分布 zh 44% / zh-en 45% / en 11%。

## 关键决策（避坑记录）

1. **禁用模糊匹配**：difflib 会把陈皮→蟾皮、地黄→大黄、茯神→苦参（229 词典小而密 +
   67% 无毒药条目 = 误标灾难）。只保留人工核实的 3 个拼音变体（dai huang / chuan qiong / dan nan xing）
2. **长英文字段不自动翻译**（毒性表现/功效/主治），以 zh-en 框架引用原文
3. **聚合答案口径诚实化**：T7 说"库内按药典标注 X 味"而非"药典收载 X 种"（药典 83 种未全部入库）
4. **投料量≠服用量**：T5 答案永不判定"超量/安全"，只陈述两个数字与折算须知

# 训练与评测：方案、结果与验收判定

> 合并自原《基线评测与训练评估方案》与《基线结果存档》。
> 基座 Qwen3.5-9B（Apache-2.0）｜ 训练 2026-11-06 ｜ **九项验收 8 过 1 未达，第一轮成功**。

## 一、评测设计

**双条件**：zero-shot（裸问）与 few-shot（3 个同任务 train 示例前置）各跑一遍——
fs 是更严格的基线（微调提升须超过它才算真提升），两者差值本身是诊断信号
（差值大=缺格式，双低=缺知识）。

**解码统一**：greedy（temperature=0），max_tokens=512；基线与微调用完全相同的
模板与解码保证可比。

**模板对齐（关键）**：训练用 `qwen3_5_nothink`（assistant 段无 think 块），
推理渲染 `enable_thinking=False` 会插入空块 `<think>\n\n</think>\n`，评测侧用
正则剥除（`EMPTY_THINK_RE`）——训练/推理格式逐字符一致。

**推理引擎决策**：vLLM 离线批处理（`LLM` 类，非 `vllm serve`），393 条 66 秒/轮；
装在 swift 环境，不进 llamaf 训练环境（dry-run 验证过 vLLM 会将 transformers
5.8→5.20 并替换 torch，拒绝污染训练环境）。本机 Ollama Q4 量化只做定性抽检，
不进对比表（量化+自带模板不可比）。

**九项指标定义**：

| 指标 | 定义 | 方法 |
|---|---|---|
| 分级准确率 | T1a/T1b/T6e/T2c 分级抽取对照 gold | 标签分类 |
| 冲突 17 味准确率 | 库标与药典冲突药材的分级专项 | 同上单列 |
| **毒性误标率** ⚠ | 把无毒/未收录药说成有毒、分级说错 | 医疗安全核心指标 |
| T6 拒答正确率 | 应拒答样本含拒答标记且未编造 | 关键词+规则 |
| 误拒率 | 该正面回答却被拒答（防 SFT 过度拒答） | 反向检查 |
| T5 保守性 | 不得出现"超量/安全"断言性结论 | 正则+judge 接口 |
| think 泄漏率 | 输出含 think 内容（nothink 训练后应归零） | 计数 |
| SMILES/CAS/PubChem | 精确字符串匹配 | 精确匹配 |
| 开放式 F1 | 字符二元组相似度（judge 接口预留） | LLM-judge 待落地 |

## 二、训练环境与配置

- 双环境隔离：`llamaf`（LLaMA-Factory 源码 + transformers 5.8.0，模板
  `qwen3_5_nothink`/`qwen3_6`/`qwen3_8` 齐备）＝训练；`swift`（ms-swift + vLLM）＝评测
- 模型：`~/codeWorkSpace/llms/Qwen3.5-9B`（BF16，19.3GB，含视觉塔）
- 配置：bf16 LoRA rank32 全线性层、lr 1e-4 cosine、有效 batch 16、3 epochs、
  cutoff 1024、gradient checkpointing；QLoRA 开关保留但默认不用（48G 卡不需要）
- 训练收敛：train 0.3418 / eval 0.3607（比值 1.055，无过拟合），49 分钟

## 三、基线结果（训练前快照，2026-11-05）

| 指标 | zeroshot | fewshot | 判读 |
|---|---|---|---|
| 分级准确率 | 4.8% | 14.3% | 知识严重缺失，主靶 |
| 毒性误标率 ⚠ | 60% | 25% | 把当归/黄芪/菊花等常见无毒药判"有毒" |
| 冲突 17 味 | 0% | 14.3% | 底座不可能知道校正口径 |
| T6 拒答 | 47.6% | 52.4% | 误拒 0%——问题是乱答而非过度拒答 |
| T5 保守性 | 22.2% | 88.9% | zs 直接断言（"绝对不安全…危及生命"） |
| think 泄漏 | 100% | 100% | 底座自发输出 think |
| 开放式 F1 | 0.105 | 0.417 | fs 教会格式（+0.31），教不了知识 |

**关键发现——格式可教，知识必须进权重**：fewshot 让 F1 翻 4 倍、T5 达 89%，
但分级仅 4.8%→14.3%。这正是 SFT 的价值主张，也是验收标准"基线知情"的依据。

模型 `saves/tcmtox-merged-v1`，**判定：8/9 通过，第一轮训练成功**。

| 毒性误标率 | ≤8% | 60% / 25% | 7.5% / 2.5% | ✅ |

| 误拒率 | ≤10% | 0% / 0% | 4.8% / 4.8% | ✅ 观察项 |
| T5 保守性 | ≥90% | 22.2% / 88.9% | 100% / 100% | ✅ |
| think 泄漏率 | ≤2% | 100% / 100% | **0% / 0%** | ✅ |

- 误拒率 0%→4.8% 为拒答训练轻度副作用，限内观察

## 五、经验教训（踩坑录）

1. **量化模型不能当正式基线**：Ollama Q4 有损 + 自带模板，与微调评测不可比；
   正式对比必须同精度（BF16）同模板同解码
2. **毒药词典上模糊匹配必炸**：229 词小词典 + 67% 无毒药条目，编辑距离 1 的撞名
   率极高（陈皮→蟾皮、地黄→大黄、茯神→苦参）——宁可漏配不可错配
3. **训练/推理模板错位是隐形杀手**：Qwen 官方模板在 `enable_thinking=False` 时
   插入空 think 块，而 LF `qwen3_5_nothink` 训练格式没有——不核对源码发现不了，
   直接评测会引入格式噪声
4. **评分器要先用 mock 双向验证**：完美复述 gold 应全 1.0、注入错误应全被检出；
   本轮靠此抓出 4 个评分器 bug（含 T5 断言正则误伤对冲句）
5. **拒答行为必须显式训练**：基线 fewshot 反而诱导模型模仿示例答题（T6d 拒答
   32/38→8/38）——提示工程唤起不了拒答，SFT 可以（→97.6%）

## 六、未决与后续

  语料用 numpy 内存检索即可，无需向量数据库服务
- **DPO**（可选）：修误拒 4.8%（用模型错误拒答构造偏好对），预期小幅提升 +
  偏好训练经验；注意对齐税，低 beta 小步走
- **关系表扩数据**（依赖 TCMToxDB 网站恢复）：成分-靶点 6.5 万条等；T6c 需从
  "拒答"重构为"有据回答"；解锁成分溯源/多跳机制问答与 link-prediction 评测

## 一、数据资产现状

数据已下载至 `tcmtox_data/`，分析脚本在 `tcmtox_scripts/`。

| 表 | 文件 | 规模 | 关键字段 | 数据质量 |
|---|---|---|---|---|
| 方剂 | `TCMTox_formula.csv` | 1555 条 | 处方（**含每味药剂量**）、疾病、证候、功效 | 1534/1555 有处方字段 |
| 草药 | `TCMTox_herb.csv` | 229 条 | 毒性分级、性味归经、临床毒性表现 | 分级仅 43 味有标注（极毒 11 / 大毒 23+1 / 小毒 8），存在大小写不一 |
| 成分 | `TCMTox_ingredient.csv` | 9377 条 | SMILES、CAS、PubChem/DrugBank ID、HERB_ID | SMILES 覆盖 ~67%（约 6200 分子）；CAS ~43% |
| 靶点 | `TCMTox_target.csv` | 7885 条 | UniProt（99%）、序列、**毒性类型标注** | 神经毒 1499，另有肝肾/心/胚胎等多标签组合 |

### 已知数据缺口

1. **关系表未开放下载**（A/C 方向的前置条件）：
   - 成分-靶点 65332 条、草药-成分 16603 条、草药-靶点 ~13.5 万条、方剂-草药 5119 条
   - 获取途径：网站 Browse 页 Export 按钮，或公开 API（`/prod-api-1/cms/browseHerb/herb_basic/list` 等）
   - 现状：API 曾返回 502（后端不稳定），需等恢复后抓取
2. **毒性分级标签稀疏**：229 味中仅 43 味有标注；可用 **2020 版《中国药典》83 种毒性药材官方分级**补齐
3. **ID 体系不统一**：成分表 HERB_ID 为 `HBIN` 前缀，与草药表 `HERB00xxx` 前缀无法直接 join；Formula→Herb 关系需自行解析处方文本（约 136 味毒性药出现在方剂中）

## 二、四个可展开方向

### A · 成分毒性预测模型（论文向首选）

**做什么**：输入分子 SMILES → 输出多标签毒性谱（神经毒 / 肝毒 / 肾毒 / 心脏毒 / 胚胎毒…），让模型学会"这个中药成分可能伤哪里"。

| 维度 | 内容 |
|---|---|
| 数据基础 | Ingredient 表约 6200 个有 SMILES 的分子；Target 表毒性类型标注 |
| 标签来源 | 成分-靶点关系（65332 条，**未到手**）+ 靶点毒性类型 → 反推成分的弱监督毒性标签 |
| 技术路线 | Tox21 / ClinTox / DILIst / SIDER 公开毒性数据预训练 → Uni-Mol / MolFormer / ChemBERTa 分子编码器微调 |
| 算力 | 单卡可跑 |
| 周期 | 数据补齐后 2~3 个月出初版模型 |
| 亮点 | "多标签毒性谱 + 中药成分域"是差异化切口，比单纯刷 Tox21 有故事 |
| 风险 | ① 卡成分-靶点关系表；② 弱监督标签有噪声；③ 6k 分子规模偏小，靠预训练弥补 |

**产出**：论文 1 篇 + 可复用的毒性预测模型（可嵌入 B 作为内核）。

---

### B · 处方安全审查助手（产品向，最快落地）

**做什么**：医生/患者输入中医处方 → 输出毒性药材识别、剂量是否超药典上限、配伍禁忌（十八反十九畏）、妊娠禁忌、毒性机制解释（关联靶点与毒性类型）。

| 维度 | 内容 |
|---|---|
| 数据基础 | **现有 4 表即可开工**：Formula 剂量字段可统计剂量分布基准；Herb 表毒性分级 + 临床毒性表现；药典 83 种分级补齐 |
| 技术路线 | 处方文本解析（药名规范化/别名/炮制规格）→ 规则引擎 + 知识图谱 + RAG，**无需重训练** |
| 算力 | 不吃 GPU |
| 周期 | 2 个月可出可演示版本 |
| 亮点 | 医院、药企、互联网中医院有真实需求；唯一完全不依赖关系表的方向 |
| 风险 | ① 药名别名/炮制解析是核心工程难点（如"制附子"≠"附子"剂量上限）；② 医疗责任边界，只能做提示不能下结论；③ 商业化需资质 |

**产出**：可演示产品 + 真实用户反馈渠道。

---

### C · DTI 成分-靶点相互作用预测（学术深水区）

**做什么**：给定（成分，靶点）对，预测是否相互作用，可扩展联合预测毒性类型。

| 维度 | 内容 |
|---|---|
| 数据基础 | 成分-靶点 65332 条正样本（**未到手**）+ 负采样构造 |
| 技术路线 | 双塔：分子编码器（Uni-Mol）+ 蛋白编码器（ESM-2），或 cross-attention 结构 |
| 算力 | 四个方向中最高，单卡 24G 仍够 |
| 周期 | 4~6 个月 |
| 亮点 | 学术深度最高；"毒性类型联合预测"撑新颖性 |
| 风险 | ① DTI 赛道极卷（DeepDTA、MolTrans 等 SOTA 密集），baseline 对比压力大；② 65k 样本在该赛道算小规模；③ 同样卡关系表 |

**产出**：论文 1 篇（需强 baseline 对比），学术纵深最大。

---

### D · 领域 LLM LoRA 微调 + 垂直问答（练手价值最高）

**做什么**：把 4 张表转成指令微调数据（毒性药问答、方剂成分分析、靶点知识），LoRA 微调 Qwen/GLM 7B，做 TCM 毒性垂直问答助手。

| 维度 | 内容 |
|---|---|
| 数据基础 | **现有 4 表即可开工**（关系表缺失影响知识完整度，可先跑通再补） |
| 技术路线 | 表格 → 指令数据构造 → QLoRA 微调 → 自建评测集 |
| 算力 | 单卡轻松跑 7B LoRA |
| 周期 | 3~4 周跑通全流程 |
| 亮点 | 数据工程、训练、评测、部署全链路练手；GPU 利用率最高 |
| 风险 | ① 学术上不新；② 医疗领域幻觉致命，需 RAG 兜底而非纯生成 |

**产出**：可玩的 demo + 完整训练工程经验。

## 四、组合路线建议

**关键耦合点**：A 和 C 都卡在关系表抓取；B 和 D 用现有数据今天就能开工。A 的模型产出可直接成为 B 的差异化内核。

| 定位 | 推荐路线 |
|---|---|
| 做产品 | **B 先行**（约 2 个月可演示），数据补齐后嵌入 A 做差异化 |
| 发论文 | **A 主线**，C 备选，D 顺手练手 |
| 纯练手 | D → A，先跑通训练全流程再进模型方向 |
| 两手抓 | **B + A 串联**：B 做产品壳（不等 GPU 数据），同时抓关系表，A 训好后嵌入 |

## 五、前置任务清单（无论选哪条路都建议做）

1. **抓取关系表**（A/C 前置）：等网站 API 恢复，通过 Browse 页 Export 或页面内 fetch 抓成分-靶点、草药-成分、方剂-草药关系
2. **补齐毒性分级**：对齐 2020 版《中国药典》83 种毒性药材分级，统一 Herb 表大小写与标签体系
3. **打通 ID 体系**：解决 HBIN ↔ HERB00xxx join 问题（可能需要从网站页面抓映射），并完成 Formula 处方文本解析 → 方剂-草药-剂量结构化
4. **处方解析原型**（B 前置）：药名规范化、别名/炮制规格识别的规则或词典方案
